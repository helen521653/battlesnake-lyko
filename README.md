# Battlesnake: змейка на Python

Змейка для [arena.battlesnake.com](https://arena.battlesnake.com), ориентированная на режим Duels.
Написана на чистом Python 3.8+ (нужна только стандартная библиотека, установка зависимостей не требуется)
и отвечает быстрее чем за 500 мс на одном ядре процессора.

## Быстрый старт

```bash
python3 server.py                      # сервер на http://localhost:8000 (порт задаётся через $PORT)
python3 -m unittest discover tests     # тесты правил, поиска и HTTP-сервера
```

Или в Docker:

```bash
docker build -t snake .
docker run -p 8000:8000 snake
```

## Локальная игра (для проверки по репозиторию)

1. Установите официальный CLI `battlesnake`:
   `go install github.com/BattlesnakeOfficial/rules/cli/battlesnake@latest`
   или скачайте бинарник со страницы [releases](https://github.com/BattlesnakeOfficial/rules/releases).
2. Запустите змейку (`python3 server.py`) и сыграйте с ней дуэль против любой другой змейки:

```bash
battlesnake play -W 11 -H 11 -g standard -t 500 \
  --name mine --url http://localhost:8000 \
  --name rival --url http://localhost:9000
```

Скрипт `scripts/local_game.sh [игр] [weights_A] [weights_B]` поднимает две копии змейки
и играет между ними серию дуэлей через CLI.

## Как устроен алгоритм

| [snake/rules.py](snake/rules.py) | Симулятор правил: одновременные ходы, еда, голод, опасные зоны, лобовые столкновения; поддержка режимов wrapped и constrictor |
| [snake/search.py](snake/search.py) | Параноидальный минимакс с альфа-бета отсечением и итеративным углублением по времени |
| [snake/evaluate.py](snake/evaluate.py) | Оценка позиции |
| [snake/weights.json](snake/weights.json) | Веса оценки |
| [snake/api.py](snake/api.py), [server.py](server.py) | Battlesnake API v1: `GET /`, `POST /start`, `/move`, `/end` |
| [bench.py](bench.py), [harness/](harness/) | Стенд для hill-climbing: независимый рефери, пул соперников, сравнение с чемпионом |
| [champions/](champions/) | Замороженные версии-чемпионы v001, v002, … |
| [experiments/JOURNAL.md](experiments/JOURNAL.md) | Журнал экспериментов |

**Поиск.** Ходы в Battlesnake одновременные, поэтому каждый ход игры раскладывается на два уровня:
мы выбираем ход, а соперник отвечает так, будто знает его (худший для нас случай). Глубина
увеличивается, пока не кончится время. В среднем удаётся просчитать около 5 полных ходов вперёд.
Ход, лучший на предыдущей итерации, считается первым, поэтому прерванная по таймеру итерация
тоже даёт корректный результат. Смерть оценивается как −1 000 000 с поправкой на номер хода:
поздняя смерть лучше ранней, ранняя победа лучше поздней. Взаимное уничтожение считается
ничьей и оценивается как полпоражения. В мультиплеере перебираются до двух ближайших соперников,
остальные ходят по жадной эвристике.

**Оценка.** Основа оценки — диаграмма Вороного: одновременный BFS от голов всех змей
определяет, кто доберётся до каждой клетки первым. Клетки тела считаются проходимыми с того
момента, когда тело с них уйдёт: сегмент `k` змеи длины `L` освобождается через `L−k` ходов.
Кроме территории, учитываются:
- перевес по длине (с ограничением сверху);
- расстояние до ближайшей «своей» еды: если змея голодна или ещё не длиннее соперника на `len_target`, оно весит сильнее;
- запертость в области меньше своей длины, своя и соперника;
- угроза лобового столкновения с не меньшим соперником;
- здоровье и опасные зоны.

**Время ответа.** Бюджет поиска равен `timeout − LATENCY_MS`, но не больше `MAX_MS` (по умолчанию 380 мс).
Обе величины задаются переменными окружения. Если сервер находится далеко от игрового движка,
увеличьте `LATENCY_MS`.

## Hill-climbing

Змейку улучшает LLM-агент в цикле «идея → правка → стенд → принять или откатить». Подход взят из статьи
[LLMs are fantastic at hill-climbing](https://www.noahrousell.com/blog/llms-are-fantastic-at-hillclimbing-will/).
Протокол и устройство стенда описаны в [HILLCLIMB.md](HILLCLIMB.md), правила для агента — в [CLAUDE.md](CLAUDE.md),
история попыток — в [experiments/JOURNAL.md](experiments/JOURNAL.md).

```bash
python3 bench.py run --idea "описание изменения"   # около 5 минут, вердикт ACCEPT/REJECT
python3 bench.py promote --idea "..."              # принятая версия становится новым чемпионом
python3 bench.py timing                            # время ответа на одном ядре
```

## Хостинг и домен

Змейке нужен постоянно доступный URL. Бесплатные тарифы с «засыпанием» (например, Render Free)
не подходят: первый запрос после простоя приходит с опозданием, и змейка пропускает ходы.

**Вариант 1: VPS + Docker + Caddy (рекомендуется).**
1. Арендуйте любой VPS с Docker. Чем ближе он к игровым серверам Battlesnake (обычно они в США),
   тем меньше задержка.
2. Направьте домен или поддомен на IP сервера (A-запись). Подойдёт и бесплатный поддомен,
   например от [DuckDNS](https://www.duckdns.org).
3. На сервере выполните:
   ```bash
   git clone <этот репозиторий> && cd battlesnake/deploy
   cp .env.example .env    # впишите DOMAIN=snake.ваш-домен.ru
   docker compose up -d --build
   ```
   Caddy сам получит HTTPS-сертификат. Проверка: `curl https://snake.ваш-домен.ru/` должен вернуть JSON с `"apiversion": "1"`.

**Вариант 2: любой PaaS, который собирает Dockerfile** (Fly.io, Railway, Koyeb и т. п.).
Сервер слушает порт из `$PORT`. Привяжите в панели свой домен и отключите засыпание.

**Публикация на арене:** на [play.battlesnake.com](https://play.battlesnake.com) создайте змейку
(Create Battlesnake) с URL `https://snake.ваш-домен.ru`, затем добавьте её в лидерборд Duels
на arena.battlesnake.com. Публикуйте как можно раньше: рейтинг растёт постепенно.

Логи сервера показывают для каждого хода глубину поиска, оценку и время ответа:
`docker compose logs -f snake`.
